# Colour schemes for Darb (drafts for Mohammed, 18 Nov)

He asked: "can you suggest other coloring for the first version". Four complete schemes, each rendered on the sign-in screen
(`option-N-signin.png`) and the home screen (`option-N-home.png`), in IBM Plex Sans Arabic. The original cream / green-black /
vermilion palette is not numbered here (he has seen it). These drafts still show the old name «مساري».

**His choice (01:3x): option 1, "the first one which is blue". It is now the product's palette.**
